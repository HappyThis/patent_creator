# 评分任务说明

你负责评估一份软件专利技术方案草稿。

输入材料：

- 评测运行任务说明。
- 测试项需求。
- agent 可访问的项目环境。
- 隐藏参考方案。
- 测试项级评分标准。
- agent 输出。

请按以下维度给出 100 分制评分：

- 环境阅读与需求理解：15 分。
- 技术问题识别：15 分。
- 技术手段具体性：20 分。
- 必要技术特征完整性：10 分。
- 问题-手段-效果闭环：15 分。
- 需求约束遵守：10 分。
- 可实施性：10 分。
- 专利化价值：5 分。

评分规则：

- 不要求 agent 输出与参考方案完全一致。
- 如果方案基于需求和项目环境且技术上合理，应允许不同于参考方案的实现路径。
- 对没有具体机制的泛泛表述扣分，例如“使用 AI”“增加缓存”“提升效率”“智能分析”。
- 对违反需求约束的方案扣分。
- 对编造当前项目环境中不存在的源码事实、具体文件、类名或 PR 实现扣分。
- 评价应具体、简洁，避免空泛评语。

返回内容：

- 总分。
- 各维度得分。
- 主要优点。
- 主要问题。
- 缺失的关键机制或无依据假设。
