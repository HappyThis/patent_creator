# 技术方案需求

当前项目希望增强 Think agent 对外部系统触发任务的支持能力。

用户希望 webhook、RPC 调用方或其他 Worker 能向 Think agent 提交一次对话任务后快速得到“已接收”的确认，而不必一直等待模型推理完成。外部调用方后续还需要能够查询这次提交的执行状态，必要时取消或清理它；如果外部系统因为超时或网络问题重试同一请求，系统也不应重复插入用户消息或重复执行同一项工作。

该能力应尽量沿用 Think 现有的会话、消息、流式执行、恢复和取消语义。用户不希望为了支持这种外部提交场景，就把普通聊天、已存在的消息保存方式或更复杂的工作流系统全部重写。

请生成一个可用于专利交底书的软件技术方案草稿。方案应说明系统如何支持外部调用方可靠提交、追踪和控制一次 agent 对话任务，以及相比现有方式能带来什么技术效果。
