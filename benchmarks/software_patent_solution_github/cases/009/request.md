# 技术方案需求

当前项目中的 Think agent 带有 workspace 文件工具，模型可以通过 read、write、edit、list、find、grep、delete 等工具操作一个持久化工作区。现有读取能力主要面向文本文件。

现在希望提升 agent 对工作区文件的理解能力：当工作区中包含图片、PDF 或其他非纯文本文件时，agent 不应该只能得到“二进制文件不可读”之类的结果。对于具备多模态能力的模型，系统应尽量把合适的文件内容传递给模型；对于不适合直接传递的文件，也应返回结构化的文件信息和限制原因。

期望能力包括：

- workspace read 工具能够区分文本、图片、PDF、普通二进制等不同文件类型。
- 文本文件仍应支持按行读取、分页读取、行号展示和长内容截断。
- 图片和 PDF 等可被模型消费的文件，应能以模型可接收的内容形式传递，而不仅是返回路径。
- 大文件应有大小限制，避免把过大的文件直接塞入模型上下文。
- 文件类型不应只依赖扩展名，应结合已有元数据和文件内容特征判断。
- 工具输出应兼顾模型可用性和用户可解释性，包括文件名、媒体类型、大小、错误原因等。
- 方案需要兼容不同 workspace 实现，例如真实 workspace、共享 workspace 或自定义文件后端。

请基于上述场景，为该项目设计一份软件专利技术方案草稿，重点说明文件类型识别、读取策略、模型输出转换、限制控制和多后端兼容机制。
