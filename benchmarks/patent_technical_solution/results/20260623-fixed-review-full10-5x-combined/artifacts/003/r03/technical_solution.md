## 技术方案

### 技术问题与设计约束

本方案面向同一用户账号下同时存在多个聊天会话的 agent assistant 系统，重点解决五类相互制约的问题：其一，每个会话需要保留独立消息历史、上下文快照和执行状态，避免一个会话的消息、工具结果或压缩摘要进入其他会话；其二，同一用户的工作区文件、外部工具连接、授权凭据和共享记忆又需要跨会话连续可用，不能为每个会话复制一份资源副本；其三，浏览器连接、子会话 RPC 或模型生成代码不能绕过统一控制面直接访问共享资源；其四，删除某个会话时只能清理该会话状态，不能级联删除用户级共享工作区和授权资源；其五，旧 WebSocket 连接、迟到工具结果或软删除窗口内的旧会话标识不能重新写入已删除会话。

为此，方案设置确定性设计约束：用户级共享资源的所有权只属于用户级资源代理；会话级执行代理只拥有本会话状态，不保存可长期复用的共享凭据，也不直接暴露共享工作区句柄；所有跨会话读写、工作区访问、浏览器或外部工具调用均经过用户级资源代理或其桥接层校验。会话级执行代理在每次写入会话状态或调用共享资源前均携带会话标识、代际号、事件序号和请求幂等键，使父级控制、会话存储和迟到结果处理具有统一判定依据。

### 总体架构：用户级资源代理与会话级执行代理

本方案采用“用户级资源代理 + 会话级执行代理”的二层组合结构。用户级资源代理也可理解为父代理或控制面代理，同一用户或租户对应一个实例；会话级执行代理也可理解为子代理、facet 或执行面代理，每一个聊天会话对应一个实例。后文统一使用“用户级资源代理”和“会话级执行代理”。用户级资源代理保存会话目录、子代理登记表、共享记忆、共享工作区命名空间、外部工具连接和授权凭据引用，并负责跨会话调度；会话级执行代理只保存本会话的消息历史、上下文块、执行队列、流式响应状态和连接订阅集合。

二层结构的职责边界被固化为资源所有权规则：共享工作区、共享记忆、外部工具连接和授权凭据的 owner 字段均指向用户级资源代理，删除或重建会话级执行代理不得改变该 owner；会话级执行代理仅保存指向共享资源的受限能力令牌或父级 RPC 端点，能力令牌包含资源命名空间、允许操作、过期时间、会话标识和代际号。会话级执行代理访问共享资源时必须经由用户级资源代理暴露的受控接口，接口在执行前校验会话仍有效、能力范围匹配且请求未过期。该规则避免共享资源在多个会话之间复制，降低凭据泄露面，并使会话上下文只能由本会话存储装配而不能从其他会话隐式混入。

### 核心数据结构与生命周期状态机

用户级资源代理维护两类相互校验的数据。会话目录行用于展示和生命周期管理，关键字段包括 $session\_id$、$tenant\_id$、$owner\_user\_id$、$generation$、$lifecycle\_state$、$directory\_visible$、$title$、$created\_at$、$updated\_at$、$deleted\_at$、$last\_event\_seq$、$ttl\_deadline$ 和 $storage\_ref$。子代理登记表用于路由真实性和子代理存在性校验，关键字段包括 $tenant\_id$、$owner\_user\_id$、$session\_id$、$generation$、$agent\_ref$、$created\_at$、$deleted\_at$ 和 $registry\_state$。两类数据以 $tenant\_id + owner\_user\_id + session\_id + generation$ 作为关联键；目录负责“是否对用户可见”，登记表负责“是否允许路由唤醒”。当二者不一致时，外部连接以登记表和代际校验为准拒绝未登记会话，目录刷新任务再根据登记表修复展示状态。

会话级执行代理的持久化空间按会话键隔离，存储键前缀包含 $tenant\_id/owner\_user\_id/session\_id/generation$，其内部记录消息事件、工具事件、上下文块版本、压缩摘要、流式响应缓冲和连接订阅集合。每条事件包含 $event\_seq$、$turn\_id$、$role$、$content\_ref$、$status$、$created\_at$ 和 $commit\_point$；同一会话内 $event\_seq$ 单调递增，用于判定消息、工具结果、压缩摘要和删除事件之间的先后关系。共享记忆记录由用户级资源代理保存，字段包括标签、版本号、内容摘要、写入者会话、写入事件号、幂等键和更新时间。审计记录保存用户标识、会话标识、代际号、资源命名空间、资源路径、操作类型、能力范围、请求幂等键、结果状态、错误类型和时间戳。

会话生命周期状态包括 $CREATED$、$DORMANT$、$ACTIVE$、$DELETING$、$DELETED$ 和 $PURGED$。创建事务提交后进入 $CREATED$；首次成功连接或开始轮次执行时进入 $ACTIVE$；无活动连接且无在途轮次时进入 $DORMANT$；收到有权限的删除请求并完成代际一致性校验后进入 $DELETING$，此时目录不可见并拒绝新写入；在途轮次 drain 完成或取消后进入 $DELETED$；超过 $ttl\_deadline$ 或显式清理完成后进入 $PURGED$。状态转换只允许按上述方向推进，旧连接或迟到任务不得把 $DELETING$、$DELETED$ 或 $PURGED$ 回退为 $ACTIVE$。

### 会话创建、连接与上下文隔离

创建会话的前置条件为用户已认证、租户边界已确定、用户级资源代理已唤醒、会话数量和存储配额未超限，并且创建请求携带有效幂等键。用户级资源代理在一个事务中生成 $session\_id$ 和初始 $generation$，写入会话目录行，写入子代理登记表，设置初始状态 $CREATED$，并可选择立即初始化会话级持久化空间或仅写入 $storage\_ref$ 等待首次连接时惰性初始化；事务成功后返回会话摘要、当前代际号和嵌套路由连接路径。若目录写入成功但登记表写入失败，事务回滚目录行；若因崩溃留下目录有行但登记表无行的中间状态，目录刷新任务将其标记为不可路由并触发重建或清除，外部连接在登记表缺失时直接拒绝。

连接请求携带用户身份、租户标识、$session\_id$、$generation$ 或目录版本、连接意图和认证材料。用户级资源代理按顺序校验身份有效性、租户归属、目录行存在性、子代理登记表存在性、会话未处于 $DELETING/DELETED/PURGED$、请求代际与当前代际一致以及用户仍具有访问权限。校验通过时，输出可连接结果并将请求转发至会话级执行代理；若认证失效返回需重新认证，若目录版本落后返回需刷新目录，若会话已删除或代际不匹配返回终态拒绝。转发后普通流式消息不经过用户级资源代理热路径，但会话级执行代理在每次接收用户消息、提交工具结果或写入流式缓冲前仍读取本地会话状态和代际，发现过期即关闭连接并返回终态错误。

同一会话内的消息执行采用轮次锁和 FIFO 执行队列。用户消息进入队列后先分配 $turn\_id$ 和递增 $event\_seq$ 并落盘为待处理事件；取得轮次锁后，系统只从本会话存储读取已提交消息、上下文块版本和压缩摘要，装配本轮上下文快照并记录 $snapshot\_version$。模型流式响应先写入本会话缓冲，工具调用结果携带 $turn\_id$、幂等键和前置 $event\_seq$ 提交；轮次完成时再把回复、工具结果和新的压缩摘要标记为已提交。状态广播只发送给订阅该 $session\_id + generation$ 的连接集合，存储键和广播通道均不包含其他会话，因此一个会话的消息、工具结果或压缩摘要不会进入其他会话的上下文装配过程。

多设备同时向同一会话发送消息时，默认按进入会话级执行代理的持久化队列顺序处理；若客户端显式请求取消前序轮次，取消请求也作为事件写入队列，只有在其 $event\_seq$ 早于目标轮次提交点时才生效。上一轮未完成、上下文快照构造失败或共享上下文降级状态未确定时，新的模型轮次不得取得轮次锁。断连后会话可进入 $DORMANT$，重连时客户端携带最近已接收的事件序号，会话级执行代理仅重放该序号之后的本会话事件和流式缓冲，不从其他会话补取状态。

### 共享资源的受控访问与跨会话协同

共享记忆读取由会话级执行代理在轮次开始前向用户级资源代理发起，输入包括用户标识、租户标识、$session\_id$、$generation$、共享标签和请求超时时间。用户级资源代理校验会话有效性和标签读取权限后，返回共享内容、$snapshot\_version$、读取时间戳和内容摘要；会话级执行代理将该结果随本轮上下文快照落盘，并在本轮模型执行期间只使用该版本。若读取超时或父级服务暂不可达，会话级执行代理记录共享上下文降级标记，将该标签作为空值或使用已落盘的最近可用快照继续本轮，并在下一轮边界重新读取；若父级返回终态拒绝，则本轮不得使用该共享标签。冻结后即使其他会话修改或删除共享记忆，当前轮次也不替换输入，下一轮再按最新版本刷新。

共享记忆写入统一提交到用户级资源代理，写入请求包含写入者会话、写入事件号、标签、操作类型、内容摘要、幂等键、时间戳以及可选的目标版本。追加型写入按用户级资源代理的单线程队列或数据库事务顺序分配新的共享版本，追加记录不覆盖旧记录；相同幂等键且内容一致时返回已提交结果，相同幂等键但内容不同则返回冲突。更新或撤回型写入必须携带目标版本并执行 CAS 校验，若当前版本与目标版本不一致，用户级资源代理返回版本冲突和当前版本摘要，由会话在下一轮重新读取后再决定是否重试。

工作区和工具访问通过用户级资源代理或桥接层执行，输入包括能力令牌、会话标识、代际号、操作类型、资源命名空间、资源路径、请求幂等键和超时时间。桥接层先对路径进行规范化，拒绝包含目录穿越、非法命名空间、越权符号链接或相对路径逃逸的请求，再校验能力令牌的操作范围、工具白名单、读写配额和过期时间；浏览器、代码执行、MCP 或扩展工具只获得窄化 RPC 能力，实际浏览器会话、网络连接、授权凭据和持久文件状态不下发到会话级执行代理。访问被拒绝时，桥接层向会话返回权限拒绝、配额超限、路径非法、工具不可用或超时取消等结构化错误；每次尝试均写入审计记录，若审计记录不可写，则除只读低风险操作可标记待补偿外，涉及凭据、外部网络或写入工作区的操作直接失败。

跨会话搜索由用户级资源代理接收查询、权限范围、结果上限和超时参数后执行。父级先从会话目录和登记表筛选同一用户、同一租户、未删除且可搜索的会话，再向各会话级执行代理并行发起检索 RPC；子会话不可达或超时的，父级记录缺失会话列表并返回部分结果。结果合并时先将各会话本地相关度分数归一化，再按归一化分数、消息时间倒序、$session\_id$ 和 $event\_seq$ 稳定排序；相同内容摘要和相同来源事件的结果去重。跨会话调度采用同一筛选规则，任务投递按用户级优先级、会话状态和创建时间确定顺序；无法投递的会话进入可重试队列，已删除或代际不匹配的会话返回终态失败。

### 删除、重连与异常边界

删除请求的前置条件为请求者具有删除权限，目录行和子代理登记表能够读取到同一 $session\_id + generation$，并且删除策略已确定为立即取消或限时 drain。用户级资源代理将会话状态从 $ACTIVE$ 或 $DORMANT$ 原子更新为 $DELETING$，设置 $directory\_visible=false$、$deleted\_at$ 和 $ttl\_deadline$，广播新的会话列表，并拒绝该会话的新用户消息和新工具请求。已取得轮次锁的流式响应可在限定时间内 drain；超过期限或收到立即取消策略时，会话级执行代理写入终止事件并释放轮次锁。未到提交点的消息、工具结果和压缩摘要不得转为正常提交，晚于删除事件返回的工具结果只能写入取消审计或被丢弃，不能覆盖删除后的会话状态。

删除后的访问判定使用 $session\_id + generation$。旧 WebSocket 连接在删除广播尚未送达时继续发送消息的，会话级执行代理在写入前检查本地状态和代际，或向用户级资源代理确认当前代际；若发现状态为 $DELETING/DELETED/PURGED$ 或代际过期，则返回终态错误并关闭连接。客户端收到会话已删除、代际过期或登记表不存在的终态错误后停止自动重试并刷新目录；仅认证过期、父级冷启动、子代理暂时不可达、共享服务超时等可重试错误允许指数退避重试。软删除窗口内不得复用同一 $session\_id + generation$，若允许用相同 $session\_id$ 重建会话，必须生成新的 $generation$ 并清理旧连接缓存键。

异常恢复按错误来源区分处理。用户级资源代理冷启动导致的首次 RPC 延迟、子代理唤醒暂时失败、共享记忆读取超时和跨会话检索超时属于可重试错误，会话级执行代理记录降级标记或缺失会话列表后继续本轮或返回部分结果，并在下一轮边界或调度重试队列中重试。持久化空间不可读、会话代际不匹配、权限被撤销、资源命名空间非法、能力令牌过期、审计写入失败且操作涉及凭据或写入的，属于终态或需人工修复错误，不得通过绕过父级控制继续执行。工具执行超时由桥接层取消底层任务并返回超时取消；若超时结果之后到达，仍须按 $turn\_id$、$event\_seq$、会话状态和代际校验，过期结果不得写入正常回复。

上述机制形成的技术效果具有明确因果关系：独立存储键、独立广播通道、轮次锁和只读取本会话快照的上下文装配规则，保证会话级上下文隔离；共享资源 owner 固定在用户级资源代理、会话删除不级联删除用户级命名空间、会话仅保存能力令牌或父级端点，保证用户级资源连续性；所有工作区、浏览器、MCP 和扩展访问均经桥接层校验并记录审计字段，保证共享资源访问可控制、可追踪；删除状态机、删除范围校验、代际终态拒绝和迟到写入丢弃规则，保证删除单个会话时不会误删或污染用户级共享资源。
