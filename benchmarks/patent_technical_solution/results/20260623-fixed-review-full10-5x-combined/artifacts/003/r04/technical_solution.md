## 技术方案

### 待解决的技术问题和总体处理路径

本方案要解决的核心问题是：同一用户账号下多个聊天会话并发运行时，既要使每个会话具有独立的消息历史、上下文和执行状态，又要允许这些会话共享用户级工作区、外部工具连接、授权凭据和跨会话调度能力。若仅按页面或浏览器连接划分状态，容易出现会话上下文串扰、共享凭据被子会话或浏览器绕过父层访问、删除某一会话时误删共享资源、在途工具调用回写覆盖删除结果、周期任务重复执行以及外部工具异常后状态无法恢复等问题。

总体处理路径是将会话私有状态、用户共享资源和访问控制状态拆分到不同边界中：会话子 Agent 只保存本会话的消息树、上下文版本、回合队列和连接状态；父 Agent 保存会话目录、子 Agent 注册关系、共享资源目录、共享授权状态和跨会话调度表；共享工作区和工具连接以父用户或资源命名空间作为所有权边界。所有跨边界访问均通过带幂等键、会话状态和资源范围的父层 RPC 完成，迟到的帧、工具结果、目录预览或调度回调只有在会话状态、回合 ID、版本号和幂等键均匹配时才能提交，否则进入取消、丢弃或补偿记录状态。

### 双层对象模型与资源边界

本方案采用“用户级父 Agent + 会话子 Agent”的双层对象模型。父 Agent 对应一个父用户标识或工作区标识，持久化会话目录、子 Agent 注册表、共享资源目录、共享授权状态和跨会话调度表；会话子 Agent 可由 Durable Object 实现，对应一个聊天会话，持久化本会话的消息树、上下文快照、回合队列、连接集合和执行状态。会话标识由父 Agent 生成或校验，子 Agent 名称由父用户标识与会话标识组合得到，使同名会话在不同父用户下不会冲突。

父 Agent 同时维护两类索引：子 Agent 注册表用于寻址和存在性判定，记录父用户标识、会话标识、子类名、子 Agent 名称、创建时间、注册状态和最后校验时间；会话目录用于展示和业务元数据，记录会话标识、标题、创建时间、更新时间、最后消息序号、最后消息预览、目录版本、删除标记和删除时间。转发、取得或删除会话时，删除标记优先于注册表有效性；目录仅用于展示时不得单独证明子 Agent 可访问，注册表缺失时也不得由浏览器连接自动创建同名会话。

创建会话时，父 Agent 先校验用户认证、父用户归属和创建幂等键，再检查目标会话标识未被有效目录项或有效注册表项占用。父 Agent 将目录项写入“创建中”状态并记录幂等键，随后创建或取得对应会话子 Agent 并写入注册表；两个写入均成功后，将目录项切换为“活动”状态。重复创建请求携带相同幂等键时返回已有会话；携带不同幂等键且会话标识已被占用时拒绝创建。若目录项写入成功但注册表写入失败，目录项保持“创建中/待恢复”状态并由父层重试或回滚；若注册表存在而目录缺失，父层以注册表为线索生成待恢复目录项，但在恢复完成前不允许浏览器连接该会话。

### 会话级隔离与执行一致性

每个会话子 Agent 具有独立的持久化存储、内存状态和 WebSocket 客户端集合。会话内设置回合队列，队列项至少包括回合 ID、客户端连接 ID、用户消息序号、工具调用 ID、幂等键、入队时间、输入消息树版本、当前状态、失败原因和重试次数。多个客户端同时发送消息时，子 Agent 先分配本会话内单调递增的消息序号，再按入队顺序处理；同一时间仅允许一个模型回合处于生成状态，后续用户输入进入等待队列或按策略取消当前回合后重新入队。

会话隔离通过“独立存储、单调序号、会话内队列和显式父层 RPC”共同实现。用户输入、工具调用结果、流式响应帧和上下文压缩任务均绑定回合 ID 与消息树版本；用户消息落库成功是触发模型响应的提交点，助手最终消息落库成功是更新目录预览和上下文快照的提交点。迟到的流式帧或工具结果只有在回合仍处于运行状态、消息树版本未被取消或分支替换、幂等键未完成时才可提交；否则写入取消记录或丢弃记录，不覆盖已经提交的较新消息、标题或预览。

一次用户消息的数据路径如下：WebSocket 帧经父路由门禁进入目标会话子 Agent 后，子 Agent 校验会话状态为活动、连接身份与父用户匹配，并为该消息分配序号和回合 ID；随后将用户消息写入消息树并记录当前消息树版本，基于私有上下文快照和允许的共享资源摘要触发模型响应。响应过程中产生的流式帧按帧序号广播给本会话连接，工具调用请求先经父层 RPC 授权和执行，工具结果再按工具调用 ID 回写到对应回合。回合完成后，子 Agent 写入助手消息、更新上下文快照和本会话全文索引，并通过父层 RPC 提交标题、最后消息预览、更新时间和可选的跨会话检索摘要。

上下文压缩任务以启动时的消息树版本和分支标识作为输入快照。压缩结果提交前，子 Agent 比较当前消息树版本、活动分支和被压缩消息范围；仅当当前版本仍等于启动版本，或新增消息位于压缩范围之后且可与压缩块顺序合并时，才写入新的压缩上下文块。若压缩期间用户创建新分支、删除消息、取消回合或工具结果改变了被压缩范围，压缩任务标记为冲突并丢弃输出，不得覆盖较新分支的上下文快照。断线重连客户端按照最后确认的消息序号和流式帧序号补拉缺失内容，子 Agent 对未确认帧进行按序缓存或重新发送，不允许客户端以乱序帧推进消息树版本。

### 共享资源层与跨会话能力

用户级共享资源由父 Agent 直接持有，或由父 Agent 调用同一父用户边界内的资源管理层持有；无论采用哪种部署形态，资源所有权均绑定父用户标识或资源命名空间，而不绑定具体会话标识。会话子 Agent 访问共享资源时提交资源 RPC，请求字段至少包括父用户标识、会话标识、资源命名空间、操作类型、资源路径或工具名、权限范围、会话状态版本、回合 ID 和幂等键。父层先校验用户归属、会话未删除、资源命名空间允许访问、操作权限满足最小范围以及幂等键未与冲突操作绑定，再返回允许、拒绝、资源不存在、需要重新认证、暂时不可用或冲突重试等结果。

工作区层实现为父用户级持久虚拟文件系统：小文件内联存储于 SQLite，大文件按阈值溢出到对象存储，SQLite 元数据记录命名空间、规范化路径、对象存储键、文件版本号或 ETag、大小、哈希、修改时间和所有权字段。父层在执行读写前对路径进行规范化，解析符号链接时限制解析深度并校验最终路径仍位于同一命名空间，拒绝跨命名空间路径、越权父目录和非法表名。写入、移动、删除、复制或符号链接修改以路径或路径集合为锁粒度，并要求请求携带期望版本号；版本匹配时提交新版本，版本不匹配时返回冲突重试，避免两个会话同时覆盖同一路径的较新内容。大文件流式写入先写临时对象和临时元数据，完成校验后再原子切换正式元数据；流中断或校验失败时清理临时对象，不改变原文件版本。

外部工具连接层采用父用户级 MCP 客户端状态管理。父层持久化服务器名称、服务器地址、回调地址、客户端标识、授权地址、传输选项、重试选项、连接状态、工具清单版本和加密后的 access token、refresh token、PKCE 校验值及短期 state。OAuth 回调到达时，父层校验 state 格式、服务器标识、创建时间和一次性消费状态；state 过期或不匹配时拒绝换取令牌。令牌过期时优先使用 refresh token 刷新，刷新失败或用户撤销授权时将服务器状态迁移为需要重新认证，立即从可用工具清单中移除该服务器工具，并向连接中的会话广播工具状态变化。

MCP 工具清单采用版本化发布规则。父层连接服务器后，先完成地址校验、认证状态校验和工具发现；工具发现失败、响应超限、工具描述解析失败或服务器能力不一致时，不更新当前可用工具清单，保留上一稳定版本或将该服务器标记为不可用。会话子 Agent 在发起工具调用时携带工具清单版本、服务器状态版本、回合 ID 和幂等键；若调用期间令牌失效、服务器断连或工具从清单中移除，父层返回认证失败、暂时不可用或工具不存在的受控结果，子 Agent 将该结果绑定到原工具调用 ID，不改写为其他工具结果，也不使用已失效连接继续重试。

跨会话调度由父 Agent 维护，调度表记录任务 ID、父用户标识、目标会话标识、回调类型、载荷、计划时间、任务类型、间隔或 cron 表达式、幂等键、状态、运行标记、重试次数、最大重试次数、上次错误和下一次执行时间。创建任务时，相同幂等键的重复请求返回已有任务；需要变更计划时必须提供任务版本或显式更新标记。alarm 唤醒后，父层按计划时间和任务 ID 批量选取到期且状态为待执行的任务，先将任务置为运行中，再按任务顺序验证目标会话仍处于活动状态并投递到会话子 Agent 或共享资源层。执行成功后标记完成或计算下一次执行时间；失败或超时后按退避间隔重试，超过最大重试次数进入死信状态并通知父用户或目标会话。父 Agent 每次任务状态变化后重新计算最近的下一次执行时间并设置 alarm，重启后通过调度表恢复该 alarm。

调度投递采用“先占有、后投递、再确认”的提交语义。父层将到期任务置为运行中时写入运行实例号和投递幂等键；投递到会话子 Agent 或共享资源层后，目标侧仅在会话仍活动、任务版本匹配且投递幂等键未完成时执行一次，并返回完成、跳过、等待重试或拒绝。若父层在投递后崩溃，重启时根据运行实例号、幂等完成标记和任务超时时间判断是补记完成、重新投递还是转入重试。周期任务上一轮仍处于运行中或超过最大执行时间未确认时，本轮不并发排队；父层记录跳过原因，并按原计划基准或配置的追赶策略计算下一次执行时间，避免同一周期任务在多个会话之间重复提交。

会话子 Agent 根据资源 RPC 结果决定当前回合走向：结果为允许时，使用返回的文件内容、工具结果或共享记忆块继续生成；结果为拒绝或资源不存在时，将错误作为受控工具结果写入本回合，不重试越权访问；结果为需要重新认证时，暂停对应工具调用并向客户端返回授权恢复指引；结果为暂时不可用时，可在不依赖该资源的情况下继续生成或将回合标记为等待重试；结果为冲突重试时，子 Agent 重新读取资源版本并按用户意图决定合并、覆盖或取消。该规则使共享资源访问结果不会直接覆盖会话私有消息或共享文件的较新版本。

### 父路由门禁与防绕过机制

为防止浏览器、嵌入页面或会话子 Agent 绕过统一控制直接访问共享资源，所有子会话入口采用包含父身份和子身份的嵌套路由，例如 `/agents/{parent-class}/{parent-name}/sub/{child-class}/{child-name}`。请求先命中父 Agent，再由父 Agent 执行门禁并转发到目标会话子 Agent。门禁校验包括：登录用户或短期签名令牌有效，令牌中的父用户标识、会话标识、授权范围、签发时间、过期时间和随机数未失效；子 Agent 注册表存在有效项；会话目录未处于删除标记、排空中、已失效或硬删除状态；请求的资源范围与令牌或 Cookie 会话权限一致。

同源浏览器连接优先使用 HTTP-only 会话 Cookie，并在父 Agent 侧绑定父用户和会话范围；跨域 WebSocket 因不能稳定携带自定义 Authorization 头，使用短期签名令牌放入连接查询参数，令牌只保存授权声明而不包含原始密钥。令牌过期、用户登出、会话进入删除流程或权限被撤销后，父层拒绝新的连接；对已建立的 WebSocket，父层或会话子 Agent 在下一次帧校验、共享资源 RPC 或目录状态广播时关闭连接，并禁止继续入队新消息。WebSocket 建立后，消息帧可以进入子 Agent 热路径，但共享资源访问仍必须经父层 RPC，子 Agent 不暴露可由浏览器直接调用的用户级资源句柄。

MCP 服务器接入由父层作为统一出口执行地址安全校验，而不是由会话子 Agent 或浏览器直接发起任意 URL 连接。父层先进行 URL 解析、协议白名单、端口策略和主机名规范化，拒绝携带用户信息、非法编码或指向本地管理端口的地址；随后对主机名执行受控 DNS 解析，并逐一校验 A/AAAA 结果，阻断回环、私有网段、链路本地、组播、未指定地址、IPv6 unique-local、IPv4 映射 IPv6 地址中的私有地址以及云元数据服务地址。建立连接时绑定已校验解析结果并设置连接超时、读超时、最大重定向次数和响应头/响应体大小上限；遇到 HTTP 重定向时，对新的目标 URL 重新执行同等校验；连接前后解析结果不一致或出现 DNS rebinding 风险时中止连接。校验失败仅将服务器状态记为不可用或需要用户更换地址，不把失败目标暴露为可调用工具。

### 删除、断连与异常恢复

会话删除采用显式状态机控制，状态依次包括活动、已标记删除、排空中、已失效和硬删除。活动状态允许连接、消息入队、工具调用和目录更新；父 Agent 接收删除请求后，先校验父用户归属、目录版本和删除幂等键，将目录项原子切换为已标记删除并广播会话列表变化。已标记删除状态禁止新的 WebSocket 连接、新用户消息入队和新的共享资源 RPC，仅允许读取删除原因、关闭连接和执行排空动作。若删除时存在运行中的模型回合、流式响应或工具调用，子 Agent 进入排空中状态，向本会话连接发送终止帧，取消未完成回合，并等待已开始的私有消息落库、取消记录和审计记录完成；排空完成后，父层将注册表项置为已失效。硬删除仅由延迟清理任务在无活动连接、无运行中回合、无待提交工具结果且删除保留期满足时执行。

删除作用域限定为目录项、子 Agent 注册关系、该子 Agent 私有的消息树、上下文快照、回合队列、连接集合、本会话全文索引、会话私有临时文件和会话私有资源引用。共享工作区、共享凭据、MCP 服务器配置、共享记忆、跨会话搜索索引和父层调度表中的非会话私有数据均以父用户标识或资源命名空间为所有权边界，不因删除单个会话而级联删除。清理任务执行前再次检查待删除对象的所有权字段，只有所有权同时匹配父用户标识和目标会话标识的私有对象才可物理删除；共享对象至多删除该会话的引用计数、订阅关系或缓存视图。旧浏览器标签页重连时，父路由门禁基于删除状态和注册表失效状态返回终止性错误，客户端停止重连，不得据此懒创建同名会话。

在途结果回写采用会话状态、回合 ID、工具调用 ID、消息树版本和幂等键的联合判定。删除标记设置后返回的工具结果、模型流式帧或调度投递结果，只能在目标回合仍处于排空允许提交的取消阶段、幂等键未完成且消息树版本未前进时，写入取消结果或审计记录；若回合已取消、注册表已失效或硬删除条件已满足，则丢弃业务结果并记录幂等完成标记，防止相同回调重复触发。目录预览、标题、共享索引摘要和调度完成状态也必须携带期望版本提交；版本不匹配时不覆盖较新的目录项、索引项或任务状态，而是进入补偿队列或冲突记录。

异常恢复按故障类型区分处理：共享记忆读取失败时返回空共享记忆块并继续本会话回合；共享搜索索引不可用时跳过跨会话检索，仅使用本会话消息树和上下文快照；MCP 连接不可用、工具发现失败或凭据解密失败时，将对应服务器迁移为不可用或需要重新认证状态，并从本轮可用工具清单中移除，不向模型暴露失效工具；父层 RPC 短暂失败时，可在幂等键未完成且会话仍活动时退避重试，超过重试上限后写入受控错误结果。私有消息落库失败、消息树版本无法确认或用户消息提交点未成立时，当前回合必须终止，不继续生成不可追溯的助手响应；对象存储大文件写入失败时清理临时对象并保留旧版本；目录更新失败时保留子层已提交消息，并由父层补偿更新标题、预览和更新时间；调度投递失败时按父层调度表记录重试、跳过或死信状态。
