## 技术方案

### 总体架构与会话边界

本方案针对同一用户账号下多聊天会话并存时的以下技术问题：若所有会话共用单一执行对象，长工具调用或模型推理会造成串行阻塞；若不同会话直接共享消息、临时工具结果或系统提示词，会产生上下文污染；若浏览器、动态代码或子会话直接持有共享 Workspace、外部连接或授权凭据，会绕过统一鉴权和审计；若删除单个会话时未区分会话私有资源与用户级共享资源，会误删工作区文件或授权配置；若多个会话同时写共享记忆或同一路径文件，会发生更新丢失或新版本被旧结果覆盖。

本方案采用“父级目录 Agent + 子会话执行体 + 共享资源桥接层”的组合架构，并在后文统一使用“子会话执行体”指代由子 Agent、子 Durable Object 或等效隔离执行单元实现的单个聊天会话。父级目录 Agent 按用户账号、租户或工作区设置，用于维护会话目录、用户级共享记忆、共享 Workspace、外部工具连接状态、授权资源引用和跨会话调度入口；子会话执行体按会话设置，用于维护该会话的消息历史、上下文块、流式响应、工具执行状态和本轮推理生命周期；共享资源桥接层由父级目录 Agent 或其宿主侧桥接组件提供，只向子会话执行体、浏览器工具和动态执行工具暴露受限 RPC 接口，不向其下发底层文件系统句柄、浏览器 WebSocket 或明文凭据。

父级目录索引记录至少包括：`session_id`、`user_id` 或 `tenant_id`、`state`、`created_at`、`updated_at`、`last_message_digest`、`child_agent_ref`、`generation`、`delete_mark`、`capability_scope` 和 `snapshot_policy`。`state` 在新建后为 `active`，收到删除请求后变为 `deleting`，私有资源回收完成后变为 `deleted`，崩溃重启且存在未提交流式片段或工具记录时变为 `recoverable`；`generation` 在同一 `session_id` 被软删除窗口内重建时递增，用于拒绝旧连接；`capability_scope` 记录该会话允许访问的共享记忆标签、Workspace 路径前缀、浏览器能力和外部 API 范围。

子会话私有存储至少包括消息树节点表、上下文块表、摘要版本表、检索索引表、工具调用记录表、流式片段表和未完成任务表。消息树节点以 `message_id`、`parent_id`、`role`、`content_ref`、`created_at` 形成会话内历史分支；上下文块和摘要版本通过 `context_id`、`summary_version` 关联到可读取的消息范围；工具调用记录以 `tool_call_id` 关联触发消息和输出片段；流式片段以 `run_id`、`chunk_seq`、`ack_cursor` 记录可续传位置。上述表均以 `session_id` 作为会话私有边界，不被其他会话直接读取或写入。

会话创建和连接按固定时序执行：客户端携带已认证用户身份、目标租户或工作区和可选标题请求父级目录 Agent；父级先校验用户身份、会话数量配额、资源配额和目录可用状态，校验失败时返回鉴权失败、配额超限或目录不可用错误；校验通过后生成 `session_id` 和初始 `generation`，创建或取得对应子会话执行体，将目录索引写入为 `active` 并记录 `child_agent_ref`、`capability_scope` 和时间字段；父级向客户端返回会话摘要和包含 `session_id`、`generation` 的子会话连接路径。客户端进入子会话时，路由请求先经过父级目录 Agent，只有索引状态为 `active` 或 `recoverable`、`user_id` 匹配且 `generation` 未过期时才转发给子会话执行体；子会话随后加载私有消息、摘要、未完成工具调用和流式游标，加载失败则将目录状态回写为 `recoverable` 并返回可重试错误。

子会话执行体的上下文组装以一次模型回合为单位触发，触发点为用户消息入队后、模型调用前；若工具结果需要继续推理，则在工具结果回填后重新组装但沿用本回合共享快照。组装输入包括本会话消息历史、私有摘要、会话内上下文块、经父级权限过滤后的共享记忆、Workspace 检索结果、已提交工具结果和本轮请求参数。处理时先读取本会话最新消息路径和摘要版本，再按 `capability_scope` 拉取允许的共享标签及 Workspace 片段，随后按系统指令、共享记忆、私有摘要、相关文件片段、历史消息、工具结果和当前用户消息的顺序拼接，并按 token 预算从低优先级的旧历史和低相关文件片段开始裁剪。输出为模型提示词、本回合执行记录、共享上下文快照标识以及各共享资源读取版本。由于临时工具结果只写入本会话私有记录，且共享内容经权限过滤和版本固定后进入提示词，其他会话的历史或临时状态不会进入本会话上下文。

### 共享资源访问与上下文隔离

父级目录 Agent 将用户级共享资源与会话私有状态分域保存。共享资源记录包括 `resource_id`、`user_id`、`resource_type`、`namespace`、`owner_scope`、`version`、`ref_count`、`credential_ref`、`revoked_at` 和 `updated_at`；其中 `resource_type` 用于区分共享记忆、共享 Workspace、浏览器能力、外部 API 和跨会话任务。共享 Workspace 采用持久化虚拟文件系统：路径先规范化为以 `/` 开头且不含 `..`、重复分隔符和超长片段的标准路径，再落入经校验的用户级命名空间；文件元数据记录 `path`、`parent_path`、`name`、`type`、`mime_type`、`size`、`version`、`storage_backend`、`object_key`、`content_hash`、`created_at`、`modified_at`。小文件内容随元数据内联保存，大文件仅保存对象存储引用 `object_key` 和内容哈希；符号链接以 `target` 字段保存并限制解析层数，解析失败或形成环时拒绝访问。每次读、写、删、移动、检索和对象存储溢出均生成审计事件，事件中关联 `user_id`、`session_id`、`request_id`、`resource_id`、路径、版本和处理结果。

共享记忆采用追加日志加版本提交点的写入协议。追加接口入参包括 `label`、`delta`、`idempotency_key`、`source_session_id`、`base_snapshot_id` 和 `request_id`；父级按提交序号而非客户端时间排序，同一 `label` 下若 `idempotency_key` 已提交，则直接返回原提交版本，避免重试导致重复记忆。提交成功后生成新的 `memory_version`，并把 `source_session_id` 和提交序号写入追加日志。整体设置接口入参包括 `label`、`content`、`expected_version`、`source_session_id` 和 `request_id`；只有当前版本等于 `expected_version` 时才允许替换，替换后旧版本转为历史版本并保留快照引用，若当前版本更高则拒绝覆盖并返回版本冲突，由子会话重新读取后选择追加、重新生成替换内容或放弃写入。

回合级共享上下文快照用于防止同一模型回合内提示词漂移。子会话在模型调用前向父级请求生成 `snapshot_id`，该快照记录允许读取的共享记忆标签及其 `memory_version`、Workspace 片段的 `file_version`、外部工具能力版本和生成时间。该 `snapshot_id` 在本轮模型调用、工具结果回填和自动继续步骤内保持有效；其他会话在此期间提交的新共享记忆或文件版本不覆盖本轮已冻结内容，只在下一用户消息入队前或本轮响应提交后触发刷新。若快照中的某项共享资源在本轮中被撤销，则后续工具调用停止使用该资源，已进入提示词的只读文本不再写回共享记忆或文件。

共享 Workspace 写入采用乐观版本校验作为默认冲突规则。写入、编辑、移动或删除请求必须携带读取时获得的 `expected_file_version`、规范化路径和 `request_id`；父级桥接层在提交前重新读取当前 `file_version`，一致时写入新内容并生成递增版本，不一致时拒绝覆盖并生成冲突结果，冲突结果包含当前版本、请求基准版本和可选冲突副本路径。对需要长时间编辑的大文件，父级可签发短期路径锁，锁记录 `lock_id`、持有会话、路径、过期时间和基准版本；锁超时后自动失效，失效锁不得继续提交。自动合并仅在基准版本、当前版本和待写版本能够形成无重叠文本差异时提交；合并失败进入待确认队列，任何旧基准写入均不得覆盖已提交的新版本。

跨会话搜索由父级目录 Agent 统一发起并合并结果。检索请求包括 `query`、`user_id`、允许的 `session_id` 集合、资源类型、时间范围和结果上限；父级先按目录索引状态、权限范围和删除标记过滤可检索会话，再向各子会话执行体并行请求消息索引或文件片段检索。返回项包括 `source_type`、`session_id`、`message_id` 或 `path`、`version`、`snippet`、`score`、`updated_at` 和 `permission_tag`。合并时先剔除权限不匹配项，再按相关度分、时间衰减和会话活跃度计算排序分；同一消息或同一文件片段重复命中时保留最高分记录并合并来源标记，同分时优先保留更新时间较新的记录。

### 统一控制、防绕过与生命周期处理

受控桥接入口由父级目录 Agent 在子会话创建、模型回合开始或工具调用前签发。桥接绑定至少包含 `user_id`、`session_id`、`generation`、`request_id`、`issued_at`、`expires_at`、`capability_scope`、允许路径前缀、允许外部主机、允许工具名和不可伪造签名或运行时绑定引用。每次桥接调用均校验绑定未过期、目录索引仍允许连接、请求会话与绑定一致、权限未超出 `capability_scope`，并校验 `request_id` 的幂等状态；重复请求在已提交时返回原结果，在执行中时返回进行中状态，在参数不一致时拒绝。过期绑定、扩大权限范围的请求、伪造路径或撤销凭据均返回终止性错误，不允许子会话通过复用旧绑定取得新增权限。

动态代码执行、浏览器工具和外部 API 调用均按照工具调用状态机持久化。子会话创建工具调用记录时状态为 `pending`，宿主侧开始执行并取得桥接绑定后变为 `running`，输出已通过父级校验且写入会话私有记录或共享资源提交点后变为 `committed`；执行异常、浏览器连接断开、外部 API 返回不可重试错误或对象存储写入失败时变为 `failed`；用户删除会话、撤销授权或父级超时控制触发时变为 `cancelled`；超过绑定有效期或最大执行时长且未提交时变为 `expired`。状态变化与输入、输出摘要、错误码、重试次数和审计事件一并持久化；只有 `committed` 状态的工具结果允许进入后续模型上下文或写入共享资源。

会话删除采用分域回收状态机。父级收到删除请求后先读取目录索引和子会话运行状态，若状态为 `active` 或 `recoverable`，则将 `state` 置为 `deleting`、写入 `delete_mark` 和新的 `generation`，立即拒绝新连接并广播目录变化；对正在流式输出的运行，保留已持久化片段和提交游标，允许在最长等待窗口内完成响应提交，超时则将未完成运行标记为 `cancelled` 或 `expired`；对正在执行的工具调用，尚未提交的调用被取消，已提交结果保留在会话私有记录或已完成的共享资源版本中。随后父级删除子会话注册项和会话元数据，将目录状态置为 `deleted`。用户级共享 Workspace、共享记忆、外部工具连接配置、授权凭据和跨会话调度队列不随单个会话级联删除；仅当共享资源记录显示 `owner_scope=session`、`ref_count=0` 且软删除窗口届满时，才回收该会话独占的临时文件、任务或引用。

流式响应恢复以 `run_id` 和递增 `chunk_seq` 为单位记录。子会话在发送每个流式片段前或发送后立即将片段内容、序号、消息标识和结束标记写入流式片段表，并维护客户端确认的 `ack_cursor`；客户端重连时携带最后确认序号，子会话从大于该序号的片段开始重放。若客户端重复确认或网络重试导致同一片段多次请求，子会话按 `run_id` 与 `chunk_seq` 去重，只返回尚未确认的片段。模型输出已经结束但客户端未确认时，结束片段和最终消息保持可重放状态，直到确认或保留期届满；保留期届满后保留最终消息，清理中间片段，并将运行状态置为已提交或可恢复。

异常处理按资源类型确定降级或终止边界。父级共享记忆短暂不可达时，子会话可在当前回合以空共享记忆继续生成，但本回合不得写回基于过期快照推导出的共享记忆；授权凭据撤销、外部 API 权限失效或请求超出允许主机范围时，本轮相关工具调用必须终止并写入 `failed` 或 `cancelled`，不得降级为未授权访问；浏览器连接断开时释放宿主侧会话并返回可重试错误，重试必须重新签发桥接绑定；对象存储写入失败时不得更新文件元数据版本，已写入的临时对象进入清理队列；子会话崩溃重启后根据目录状态、未完成工具记录和流式游标恢复为 `recoverable`，重新扫描未提交记录，已提交版本不得回滚，未提交操作按幂等键重试或标记失败。通过子会话私有存储、回合级快照、父级逐次校验、版本化写入、软删除窗口和恢复扫描，本方案分别实现上下文隔离、防绕过访问、防误删、并发协同和异常恢复。
