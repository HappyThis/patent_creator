## 技术方案

### 总体组合架构

本方案针对多会话历史与用户级共享资源混放时产生的路由混淆、上下文串线、共享文件误删、删除竞态、凭据泄露和恢复写错会话等问题设置以下不变量：会话级数据只能在所属会话命名空间内读写；用户级共享资源以用户或工作区命名空间持有，不随任一会话删除而级联删除；跨越父目录、子 Agent、资源代理和 host 侧执行环境的访问必须经过父目录校验并携带当前会话版本；客户端提交的租户、权限和内部路由字段不得直接作为可信依据。

本方案采用“父目录 Agent + 子 Agent + 用户级资源代理 + host 侧执行环境”的组合架构。父目录 Agent 负责用户级会话目录、租户认证、嵌套路由和会话生命周期控制；子 Agent 只负责单一会话的消息存储、上下文组织和模型执行；用户级资源代理负责共享工作区、外部工具连接、授权凭据、共享记忆和调度任务；host 侧执行环境持有浏览器、沙箱或底层外部连接句柄。四类主体之间以受控 RPC 或内部可信通道连接，形成会话态与用户级资源态分离的执行边界。

父目录 Agent 保存会话索引和共享状态。会话索引记录至少包括 $parentId$、$sessionId$、标题、状态、创建时间、更新时间、最后消息摘要、当前叶子消息标识、$generation$、删除时间、清理时间、权限范围和最后写入请求标识。客户端展示侧边栏、创建会话、重命名会话、删除会话和选择当前会话时，先与父目录 Agent 交互；进入某一会话时，连接被路由到对应子 Agent，使消息流、工具调用流和恢复流均绑定到该子会话。

父子 Agent 之间通过嵌套路由和受控远程调用建立关系。内部请求统一携带 $parentId$、$sessionId$、$generation$、调用者身份、操作类型、请求标识、时间戳、权限范围和策略标签；响应返回成功、拒绝、终止、需重连、需刷新上下文或可重试失败等结果码。路由路径和重连缓存均包含父目录身份与子会话身份，从而避免不同父目录下同名子会话混淆；子 Agent 访问共享记忆、共享工作区或统一工具能力时，只能经由用户级资源代理发起带上述字段的受控请求。

会话创建流程按“认证—建索引—初始化子 Agent—返回目录状态”的顺序执行：父目录先验证用户身份和用户级命名空间是否存在，再以 pending 状态写入会话索引并分配新的 $sessionId$ 与 $generation$；子 Agent 初始化消息表、上下文表、流状态表和会话搜索索引后，父目录将索引状态置为 active 并广播会话列表。若子 Agent 初始化失败，父目录将索引标记为 failed 或回滚 pending 记录，并向客户端返回可重试错误，避免出现目录显示存在但实际不可连接的半创建会话。

### 会话级隔离机制

会话级子 Agent 以 $sessionId$ 作为命名空间，独立保存消息历史、上下文块、压缩摘要、会话内搜索索引、流式响应检查点、终止标志和恢复状态。子 Agent 的会话状态记录包括 $sessionId$、$parentId$、$generation$、当前叶子消息标识、运行状态、当前流标识、最后确认 chunk 序号、终止原因、上下文版本、压缩摘要版本和更新时间。任何写消息、写索引、写摘要、接收工具结果、广播状态或后台清理的动作，均先比较父目录当前 $generation$ 和删除状态；不一致时拒绝写入并进入终止处理。

消息树记录包括消息标识、父消息标识、角色、内容摘要或内容指针、分支序号、创建时间、状态、可见性、所属 $generation$ 和索引版本。新用户消息默认挂接在当前叶子节点之后并成为新的当前叶子；模型回复挂接在对应用户消息之后；重试或再生成在同一父节点下写入新的兄弟分支，并按创建时间和分支序号排序。并发再生成时，子 Agent 为每个候选回复分配独立分支序号，只有被用户选择或策略选中的分支更新当前叶子，未选分支保留为可检索但不进入默认上下文路径。

消息处理流程按“校验会话状态—写入用户消息—构造上下文—执行模型—提交回复—更新派生状态”的顺序执行。用户消息写入后生成或更新与该回合相关的上下文块；压缩任务记录已压缩的消息范围、摘要版本和源叶子标识；搜索索引随消息提交进行增量更新，并在分支切换时仅改变当前叶子指针而不删除其他分支索引。删除或回滚某分支时，该分支消息被标记为 hidden 或 rolled_back，默认上下文、最后消息摘要和跨会话索引过滤该状态，但审计记录和必要的会话内检索标识仍可保留。

可恢复流以 $streamId$、chunk 序号、字节偏移或 token 偏移、检查点时间和完成状态记录输出进度。子 Agent 每输出一个或一组 chunk 后保存检查点，客户端重连时提交 $parentId$、$sessionId$、$generation$、$streamId$ 和最后确认 chunk 序号；子 Agent 只补发序号更大的 chunk，并对重复确认执行幂等忽略。若终止信号与模型流输出并发到达，终止优先于后续 chunk 写入；迟到的工具结果、模型 token 或索引更新被标记为 late_result 并归档，不再修改当前回复、最后消息摘要或共享资源。

### 用户级共享资源层

用户级资源代理统一持有共享工作区文件、外部工具连接、授权凭据、跨会话共享记忆、跨会话搜索入口和后台调度任务。资源代理的请求记录包括 $parentId$、$sessionId$、$generation$、请求标识、操作类型、目标资源、路径或工具名称、权限范围、基准版本、幂等键、时间戳和调用来源。共享资源以用户账号或工作区作为命名空间；因此，会话新建、切换、删除只改变会话索引和子 Agent 状态，不改变共享资源的所有权、命名空间和持久化位置。

共享工作区写入流程按“规范化路径—校验权限—比较版本—写临时对象—原子替换—广播变更”的顺序执行。资源代理先将相对路径、重复分隔符和上级目录引用规范化，拒绝越出用户级根目录的路径、符号链接逃逸和未授权扩展名；随后比较文件基准版本或获取文件锁，多个会话同时写入同一文件时，只有版本匹配或持锁请求可以提交。写入先落到临时文件或临时对象，校验哈希和大小后再原子替换目标版本；失败时删除临时对象并返回可重试或冲突结果，不广播成功变更。差异生成以调用方声明的基准版本和当前版本为输入，变更广播限定在同一用户级命名空间内的订阅会话。

外部工具连接和授权凭据由资源代理封装为最小权限能力，不向子 Agent、浏览器脚本或沙箱代码返回原始令牌。令牌记录包括服务标识、授权主体、作用域、过期时间、刷新令牌引用、撤销标记、回调地址指纹和最近校验时间；调用工具前先检查撤销和过期状态，必要时由资源代理刷新令牌或重建连接。外部回调必须携带可验签状态值并匹配登记的回调地址；连接断开时，资源代理按幂等键重连并重新绑定用户级命名空间。若模型或脚本请求扩大权限、导出凭据、改写回调地址或访问未登记工具，代理根据权限范围和策略标签拒绝请求。

共享记忆条目包括记忆标识、主题键、事实内容、来源会话、来源消息、置信度、可见范围、状态、版本、创建时间和撤销标记。追加型写入使用幂等键和主题键去重；当不同会话追加相同事实时合并来源和提高置信度，当追加相反事实或过期事实时保留多版本并标记为待确认，而不是立即覆盖既有有效记忆。全量替换必须携带目标版本，版本不匹配时保留旧版本并返回冲突结果；共享记忆进入模型提示前在会话回合边界刷新，已撤销、低置信度或无权限可见的条目被过滤。

跨会话调度任务由用户级资源代理或父目录登记，任务记录包括任务标识、触发时间或周期、目标会话或共享目标、载荷摘要、幂等键、重叠执行策略、最近执行结果和权限快照。触发任务前重新校验目标会话状态、$generation$ 和权限；若目标会话已删除，则仅允许执行明确标记为用户级的共享任务，禁止将结果写回已删除子会话。该规则使周期性摘要、同步或外部工具轮询不因单个会话断开而丢失，同时避免后台任务绕过会话删除状态继续改写会话历史。

### 统一访问控制与防绕过机制

统一访问控制按固定顺序执行：先验证连接凭据，再将凭据中的用户或租户与 $parentId$ 匹配；随后查询父目录会话索引，确认 $sessionId$ 存在、状态允许访问且 $generation$ 一致；再按用户、会话、操作类型和资源类型执行速率限制；最后根据权限范围、策略标签、资源路径和工具名称进行策略检查。任一阶段失败均返回拒绝、需重连或终止结果，未登记、已删除或 generation 过期的子会话不被懒创建为可访问对象。

对于 WebSocket 等不能携带常规授权头的连接，同源场景使用 HTTP-only cookie 并结合 CSRF token 或 Origin 校验，跨域场景使用短期签名令牌或 JWT。令牌字段包括用户标识、$parentId$、允许的 $sessionId$ 或会话范围、过期时间、签发时间、随机数、权限范围和签名；父目录校验签名、过期时间、随机数是否已使用以及来源域名。长连接接近过期时，客户端需通过父目录续期；续期失败后只能完成已确认的只读恢复，不允许提交新消息或共享资源写入。

父目录通过可信通道向子 Agent 注入经验证的用户身份、父目录路径、会话标识、generation 和权限范围，并对内部字段签名或利用内部连接元数据传递；子 Agent 丢弃客户端请求中同名的内部字段。浏览器执行环境、代码沙箱和模型工具调用不持有共享工作区、授权凭据或外部连接的底层句柄，实际浏览器会话、CDP 连接、文件系统写入器和外部工具客户端由 host 侧或资源代理持有。所有来自浏览器、沙箱和外部工具的回调必须回到父目录或资源代理复验会话状态、generation 和权限后才能写入，从而在提示注入场景下仍通过窄化 RPC、字段隐藏和边界复验阻断凭据导出与越权资源访问。

并发冲突按优先级处理：删除高于重连和新写入，终止高于流式追加，权限撤销高于已排队工具调用，较新版本的共享资源状态高于旧版本写入，父目录索引状态高于子 Agent 本地缓存。重命名与删除并发时，删除提交后拒绝重命名结果；父目录最后消息摘要更新与子 Agent 回复提交并发时，以子 Agent 已提交消息的版本和请求标识进行补偿更新；多个会话同时写同一共享文件或共享记忆时，由资源代理的文件版本、锁或记忆版本条件决定提交者，失败方获得冲突结果而不是覆盖成功方。

### 会话生命周期与删除边界

会话生命周期状态包括 active、quiescing、deleted、purging、purged 和 terminated。active 状态允许新消息、模型流、工具回调、索引更新和共享资源请求；quiescing 状态禁止新连接和新用户消息，但允许删除请求到达前已经登记的流式响应在受控窗口内写入会话级最终状态；deleted 状态拒绝新写入、工具回调和共享资源回写，仅允许读取必要审计信息和执行清理；purging 状态执行后台清理；purged 状态表示会话级数据已回收；terminated 状态用于 generation 不一致、权限撤销或强制终止后的连接关闭。

删除会话流程按“标记 quiescing—递增 generation—广播目录变更—终止或收敛执行—标记 deleted—后台清理”的顺序执行。受控窗口由正在执行的模型流或工具调用的最大允许完成时间、平台超时和用户策略共同确定；窗口内仅允许写入该会话自身的最终回复截断记录、终止原因和审计状态，不允许改写共享工作区、共享记忆或外部凭据。窗口结束后，父目录下发强制终止信号；迟到的工具回调和模型 token 被归档为 late_result，不更新最后消息摘要、索引或共享资源。

generation 校验覆盖客户端重连、子 Agent 写入消息、更新索引、写入压缩摘要、更新最后消息摘要、接收工具结果、回写共享资源、执行后台清理和广播状态。每个异步任务启动时记录启动 generation，提交前重新向父目录读取当前 generation 和状态；若不一致或状态不是允许写入的状态，任务结果只可归档为审计记录并返回终止结果。该机制使删除操作幂等，并通过“会话级状态版本比较 + 用户级资源不级联删除”同时防止陈旧连接改写会话和误删共享资源。

异常恢复采用补偿而非跨边界覆盖。若父目录创建索引成功但子 Agent 初始化失败，pending 记录被重试、标记 failed 或回滚；若子 Agent 消息已提交但父目录最后消息摘要更新失败，父目录通过请求标识和消息版本进行补偿扫描并重建摘要；若资源代理写文件失败，临时对象被清除并返回冲突或可重试错误，不发布成功广播；若共享记忆服务短时不可用，子 Agent 可将本会话候选事实保存在会话级待同步队列，恢复后按主题键、版本和置信度重新合并，而不是直接覆盖父目录当前共享记忆。

### 跨会话检索与一致性边界

跨会话检索由父目录 Agent 统一编排，并根据会话数量和索引新鲜度选择扇出搜索或父侧索引：活跃会话数量较少或需要最新分支消息时，父目录向符合权限和状态条件的子 Agent 扇出搜索；会话数量较多或需要快速全局召回时，父目录使用由子 Agent 增量上报的跨会话摘要索引。跨会话索引记录包括索引标识、$parentId$、$sessionId$、消息标识、分支标识、摘要文本、权限范围、消息状态、索引版本、更新时间和删除标记；子 Agent 每次提交消息、分支切换、分支隐藏或会话删除时上报增量变更。

检索流程按“确定可见会话集合—执行扇出或索引查询—过滤不可见状态—排序去重—生成引用上下文”的顺序执行。父目录过滤 deleted、purging、purged、无权限或索引过期且无法刷新的会话；搜索超时后可返回已完成子会话的部分结果，并标记结果是否完整。排序综合相关性、消息时间、会话活跃度、权限可见性和用户选择；同一消息同时命中摘要索引和原始索引时，以消息标识和分支标识去重。命中内容不得直接写入当前会话历史，只能作为带来源会话、消息和分支定位的引用上下文或摘要上下文，并可在用户确认后连接到来源会话恢复完整路径。

共享上下文和检索结果的可见性在会话回合边界刷新。父目录不可用时，子 Agent 只能使用已缓存且未过期的会话内上下文继续只读或低风险响应；共享搜索不可用时，系统退化为本会话搜索；资源代理不可用时，涉及文件、凭据或外部工具的操作返回可重试失败而不伪造成功；子 Agent 不可用时，父目录保留会话索引并提示重连或恢复。上述降级路径分别对应命名空间隔离、完整路径路由、资源代理校验和上下文刷新边界，使单个共享服务故障不会污染其他会话或错误提交共享资源写入。
