## 技术方案

### 共享知识层与本机运行态层

本方案将面向团队共享的 Markdown 知识文件划分为共享知识层，将随检索、访问和排序不断变化的运行时信号划分为本机运行态层。共享知识层用于保存适合人工审阅和版本控制的稳定内容，包括知识标题、正文、标签、关键词、摘要、关联关系、来源说明以及经人工或低频策展确认的成熟度标记；本机运行态层用于保存访问次数、检索命中次数、近期使用时间、动态重要度、动态成熟度推断、排序反馈、衰减中间值和索引缓存状态等高频变化数据。两层数据在物理存储上分离，运行时信号不回写到共享 Markdown 的 frontmatter 或正文中。

共享知识层与本机运行态层通过知识项标识关联。知识项标识可以由知识文件相对路径、知识树根路径、共享来源别名、内容摘要和可选的文件内稳定标识组合形成；其中，相对路径便于定位当前文件，知识树根路径和来源别名用于区分本地知识与共享知识源，内容摘要用于在文件移动或重命名后辅助识别同一知识项。通过该组合标识，系统能够在多工作区、多 worktree 或只读共享源并存的情况下，避免把一个来源的访问热度错误叠加到另一个来源。

### 读取融合与评分计算

检索或问答请求到达时，系统先从共享知识层读取 Markdown 文件并构建文本索引，获得与查询语义或关键词匹配的候选知识项；随后按照候选知识项的稳定标识读取本机运行态层中的动态信号，在内存中完成融合评分。融合评分可以包括文本相关度、共享层中的低频重要度、运行态层中的访问热度、近期使用度、成熟度加权、来源类型加权以及父子层级传播分值。评分结果只作为本次检索排序、截断和上下文选取的依据，不写回共享知识文件。

动态信号的时间衰减采用懒计算方式执行。本机运行态层保存最后更新时间、访问计数和必要的累计值，检索时根据当前时间与最后更新时间计算近期使用度和动态重要度，而不是在时间流逝时周期性改写共享知识文件。成熟度判断可以采用带滞回阈值的分层规则，使知识项在 draft、validated、core 等等级之间变化时需要跨过不同的晋升阈值和降级阈值，从而避免排序和访问的小幅波动造成成熟度频繁振荡。

### 写入聚合与本机持久化

对于访问命中、检索返回、用户选择、排序反馈等高频事件，系统先写入内存聚合区，以知识项标识为键累加增量，并记录最近触发时间和触发来源。聚合区在达到预设数量、预设时间、进程退出、索引重建前或查询空闲窗口时，将增量批量刷入本机运行态层。刷入过程采用临时文件写入后原子替换、轻量事务或追加日志压缩的方式，保证本机信号不会因进程中断产生半写状态，同时避免每次命中都触发磁盘写入。

本机持久化记录不替代共享知识内容，而是以增量覆盖的方式参与运行时计算。每条记录至少包括知识项标识、访问增量、最近访问时间、检索命中增量、反馈增量、动态重要度参数和记录版本。系统刷入增量时先读取已有记录并合并同一知识项的增量，再写入新的本机状态；当同一知识项在短时间内被多次检索命中时，只增加聚合计数而不产生多次共享文件修改。

### 清理、迁移与共享源一致性

系统在扫描共享知识层、重建索引、同步知识树或移除知识源时，对本机运行态层执行一致性校验。校验过程以当前可见的 Markdown 文件集合为基准，逐项比对运行态记录中的知识项标识；对于找不到对应 Markdown 文件的记录，系统将其标记为孤儿记录，并按照保留窗口归档或删除。对于文件移动或重命名导致的路径变化，系统可以利用内容摘要、旧路径映射或知识文件中的稳定标识迁移运行态记录，迁移失败时降级为新知识项而不污染共享文件。

一致性校验还包括共享源边界处理。当知识项来自只读共享来源或外部项目知识树时，本机运行态记录携带来源根路径和来源别名，系统只在本机命名空间内更新对应动态信号；若共享来源被移除、别名变更或根路径不可访问，相关动态记录进入隔离状态，不参与默认检索排序，待来源重新出现且标识匹配后再恢复。这样既保留本机使用经验，又不会把本机运行偏好写入团队共享知识树。

### 可选实施方式

在一种实现中，本机运行态层可以采用位于工作区本地缓存目录的侧车文件、嵌入式键值数据库或追加式日志文件实现，并可以按照工作区、知识树根路径、共享来源别名和用户身份进行命名空间隔离。对于共享只读知识源，系统仍可记录本机访问热度和排序反馈，但该记录仅影响本机检索排序，不向共享来源回写。对于需要团队共享的成熟度信息，系统将其限定为人工确认或低频策展结果；由访问热度和近期使用推导出的成熟度只作为本机动态覆盖值参与融合评分。

在另一种实现中，系统可以设置可控的共享回写通道，仅允许低频、人工确认或满足阈值条件的策展结果进入共享 Markdown。例如，当某知识项长期保持高访问度且经用户确认后，系统只更新共享层中的人工成熟度或摘要说明；访问计数、检索命中、即时排序权重和衰减值仍保留在本机运行态层。该通道将“可共享的知识质量判断”与“不可共享的本机使用噪声”分开处理。
