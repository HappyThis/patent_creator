# Case 001 表达专项标尺

## 配图（optional）

不画图不扣分。若使用配图，可以表达运行时独立适配、状态发现、版本化解析、统一会话视图、解析可信度、能力门禁或故障隔离中的任意正确关系；不因图较简单、偏装饰性或未覆盖全部机制而扣分。把未知 runtime 画成已确定格式、绕过适配层直连统一视图，或默认所有能力可用，属于实际错误。

## 公式（optional）

不写公式不扣分。若使用公式定义可信度、能力可用性或候选状态来源排序，只按实际写出的关系评价，不要求覆盖全部机制；关系正确时不因简单或装饰性扣分。公式应定义其使用的变量、条件和边界，并保持“未知即不承诺”的机制；材料未支持的固定权重、阈值或概率不得写成既有事实。
