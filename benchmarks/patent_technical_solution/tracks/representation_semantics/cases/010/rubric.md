# Case 010 表达专项标尺

## 配图（recommended）

高质量配图应表达一次 workspace 读取如何经过后端能力抽象、文件识别、限制判定和模型输出转换。核心语义包括：

1. 真实 workspace、共享 workspace 或自定义后端通过统一的状态、文本和字节读取能力接入，不把某一存储实现写死在工具中。
2. 读取请求先获得路径、名称、大小和媒体类型等状态；媒体类型缺失或过于宽泛时，再根据文件头或部分内容识别文本、图片、PDF 或普通二进制。
3. 文本路径保留原有行号、分页、总行数、长行截断和读取范围说明。
4. 可被模型消费的图片或 PDF 在通过字节大小限制后转换为对应的模型内容块，并携带文件名、路径、媒体类型和大小等来源说明。
5. 目录、文件不存在、不可读、超限、转换失败或模型不支持的普通二进制进入结构化降级路径，而不是把原始字节当作大段 base64 文本塞入上下文。

可以使用决策流程图、后端边界图和模型内容块转换图的组合。只画“用户—workspace—模型”的通用三框图，没有表达类型分流、限制或降级语义，应判为部分正确；若只依赖扩展名、让超限文件绕过限制、把所有二进制都作为文本返回，或破坏已画出的文本分页语义，应按技术错误扣分。

## 公式（optional）

不写公式不扣分。若使用公式表达分页范围、长行截断或字节上限判定，应定义变量、单位和边界，并与正文的包含/超限规则一致。只要实际写出的关系技术正确且不误导，即使关系简单、偏装饰性或未覆盖全部机制也不扣分；边界方向错误、单位混用、关键变量未定义或与正文限制矛盾时，应按实际技术错误扣分。
