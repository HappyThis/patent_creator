# Case 004 表达专项标尺

## 配图（optional）

不画图不扣分。若使用配图，可以只表达任务、会话、agent、运行记录、生命周期事件、产物引用、评估附着或外部查询中的一部分；只要实际画出的对象和关系正确，就不因图较简单、偏装饰性或未覆盖完整链路而扣分。若图把评估结果画成覆盖运行主状态、把人工日志画成唯一事实源，或对其声称已表达的触发来源与产物画出错误关系，才按具体错误程度扣分。

## 公式（optional）

不写公式不扣分。若使用公式聚合成本、质量或排行榜，只按实际写出的关系评价，不要求覆盖全部机制；关系正确时不因简单或装饰性扣分。公式应定义其样本集合、缺失值和聚合边界，且不得把材料未确认的权重写成固定事实。只用于举例且明确可配置的等价表达可接受。
