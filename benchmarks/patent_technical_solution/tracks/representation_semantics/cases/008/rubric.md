# Case 008 表达专项标尺

## 配图（recommended）

高质量配图应表达主 agent、父侧子运行注册表、一个或多个独立子 agent、事件持久化/回流和客户端主会话视图之间的完整链路，并体现稳定 run id、并行子运行、流式事件序号、断线重放与 live 去重、最终工具结果、取消/清理和访问门禁。等价结构图、事件时序图或状态图均可。仅画“主 agent 调用子 agent 后汇总”的三框图，即使已画关系本身正确，也因缺少保留身份、事件回流和恢复关系而只能判为 `partially_correct`；已画关系错误、矛盾或误导时再按错误程度扣分。

## 公式（optional）

不写公式不扣分。若使用公式描述事件去重、顺序、并发上限或保留时限，只按实际写出的关系评价，不要求覆盖全部机制；关系正确时不因简单或装饰性扣分。公式应定义其使用的事件标识、序号或时间边界，并与正文协议一致；材料未支持的固定并发数、权重或超时值不得写成必然条件。
