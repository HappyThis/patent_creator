# Case 009 表达专项标尺

## 配图（recommended）

高质量配图应表达模型生成代码、浏览器隔离容器、注入工具代理、主页面工具注册表和上层 agent chat 的边界与双向消息流，并至少体现 ready、execute、带 call id 的 tool-call/tool-result、execution-result/error/timeout 和 cleanup。图中应显示生成代码不能直接访问主页面，真实客户端工具只在主页面校验后执行。仅画关系正确的普通前后端架构、但没有覆盖上述隔离与协议核心关系，应判为 `partially_correct`；让沙箱直接调用页面工具或 DOM 等已画技术关系错误时，再按错误程度扣分。

## 公式（optional）

不写公式不扣分。本题主要是隔离和协议机制。若使用公式表达 call id 映射、超时判定或资源上界，只按实际写出的关系评价，不要求覆盖全部机制；关系正确时不因简单或装饰性扣分。公式应定义其使用的集合、时钟和边界，并与并发 promise 关联及清理机制一致；不得编造无依据的固定安全评分。
