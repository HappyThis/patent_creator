# Case 013 表达专项标尺

## 配图（recommended）

高质量配图应把分层近邻图搜索、候选/结果双队列、可插拔停止策略和多向量对象计数表达为一条可追踪的运行链。核心语义包括：

1. HNSW 上层逐层贪心下降，到第 0 层后转为最佳优先扩展。
2. 最近的待展开候选用于继续搜索；当前最差的保留结果形成下界并在超限时优先淘汰，两类队列不得互换。
3. 候选考虑、结果加入、超量移除、下界更新、停止判断和最终过滤的方向及先后关系与正文一致。
4. 多向量场景中多个向量可映射到同一逻辑对象，搜索与最终截断使用“不同对象数”，而不是简单使用向量条数。

可以是一张综合流程图，也可以是分层搜索图与多向量关系图的组合。只有“客户端—索引—结果”的通用装饰图没有表达本题核心关系，应判为部分正确；若把最差结果当作下一扩展节点、把最近候选优先淘汰，或把向量数等同于不同对象数，应按错误程度扣分。

## 公式（recommended）

高质量公式应同时定义距离量纲、范围条件、停止/考虑条件和不同对象数。至少应覆盖以下核心语义：

1. 距离与范围阈值使用一致量纲。例如项目使用平方 L2 距离时：

   \[
   d^2(q,x)=\sum_i(q_i-x_i)^2,\qquad d^2(q,x)\le\varepsilon^2
   \]

2. 定义最近待展开距离 \(c\)、当前最差保留距离 \(b\)、结果数 \(n\) 和最小/最大结果界，并给出可判定的停止关系。等价关系例如：

   \[
   \operatorname{stop}_{\varepsilon}=
   ((c>b)\land(n=n_{\max}))\lor
   ((c>\varepsilon^2)\land(n\ge n_{\min}))
   \]

3. 给出新邻居是否值得进入待展开候选集合的等价条件，例如：

   \[
   \operatorname{consider}_{\varepsilon}=(n<n_{\max})\lor(c_{new}<b)
   \]

4. 以集合基数表达逻辑对象数，而不是向量数：

   \[
   D(R)=\left|\{\operatorname{doc}(x):x\in R\}\right|
   \]

公式不要求逐字符复制参考关系；其他距离空间或等价保守停止条件也可接受，但必须定义变量、边界和单位，并说明 \(n_{\min}\) 是允许终止前的最低暂存或探索门槛，不是最终返回数量保证；半径内结果不足时不得用范围外结果补足。`consider` 条件只决定邻居是否进入搜索候选、从而可能继续扩展，并不保证该向量最终留在返回集合。只有普通距离公式而没有范围或终止关系，属于部分正确；平方距离与未平方半径直接比较、停止不等式方向错误或对象数定义错误，应按技术错误扣分。
