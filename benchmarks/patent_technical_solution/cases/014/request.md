# 技术方案需求

给定项目快照提供了闭合、断开和半开状态的断路器，并能根据一段统计周期内的请求结果决定是否切换状态。现有统计在周期边界整体清空：周期末尾的失败会很快被遗忘，相邻两个周期的连续异常可能被拆开，而某个周期早期的异常又可能在整个周期内持续影响判断，导致状态切换对边界时间过于敏感。

现在需要增加按时间连续滚动的请求结果统计能力，使较旧数据逐步过期，并允许配置总统计时长和更新粒度。新机制应与现有固定周期行为兼容，并正确接入请求开始、请求完成、断路器状态转换、长时间无请求、并发执行和两阶段结果回报。项目还包含共享状态的分布式断路器，因此方案需要说明多个实例保存和恢复统计状态时如何保持时间窗口一致。

请探索给定项目快照，生成一个可用于专利交底书的技术方案草稿。方案应围绕时间窗口划分、增量统计、过期处理、跨边界请求、状态机协同、共享状态和异常配置提出合理、深入且可实施的解决方法，不要只提出缩短原有统计周期或定时全量重算。
