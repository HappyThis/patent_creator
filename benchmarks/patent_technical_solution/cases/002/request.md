# 技术方案需求

给定项目快照中的 agent 系统支持用户以对话方式触发智能处理流程。现在需要支持外部系统通过 webhook、RPC 或其他程序化方式提交一次对话任务。外部调用方提交后应快速获得“已接收”的确认，不必等待模型推理完成；后续可以查询任务状态，必要时取消或清理该任务。

外部系统可能因为超时或网络异常重复提交同一任务，系统应避免重复写入用户输入或重复执行。agent 运行环境可能发生休眠、重启或执行中断，系统需要在恢复后判定任务处于哪个阶段。

请探索给定项目快照，生成一个可用于专利交底书的技术方案草稿。方案应围绕外部提交场景下的可靠接收、执行管理和恢复一致性提出合理、深入且可实施的解决方法。
