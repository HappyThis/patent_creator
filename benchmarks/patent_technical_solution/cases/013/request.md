# 技术方案需求

给定项目快照提供了基于分层近邻图的向量索引和固定数量的近邻检索能力。现有检索接口主要围绕“返回距离最近的若干向量”设计，但实际业务还存在两类结果目标。

第一类业务只关心指定距离范围内的向量。不同查询可能使用不同的距离上限，结果数量事先并不确定；如果继续固定返回若干近邻，会把范围外结果带给上层，或者为了覆盖低密度区域而执行不必要的搜索。第二类业务中，一个逻辑文档、商品或对象可能由多个向量共同表示，业务要求返回若干不同的逻辑对象，而不是被同一对象的多个相似向量占满结果。

现在需要扩展检索机制，使搜索过程能够依据不同结果目标决定候选是否保留、何时继续扩展以及何时结束，并为距离范围检索和多向量对象检索提供可实施方案。方案应兼顾召回率、候选数量边界、结果排序、删除与过滤场景，以及原有普通近邻查询的性能，不能简单地把固定数量设置为一个极大值后再由调用方全量过滤。

请探索给定项目快照，生成一个可用于专利交底书的技术方案草稿。方案应具体说明搜索状态、候选集合、结果集合、逻辑对象聚合、终止判定、异常边界和验证方式，并允许后续扩展新的结果目标。
