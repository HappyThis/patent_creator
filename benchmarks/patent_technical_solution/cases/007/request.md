# 技术方案需求

给定项目快照中的 agent chat 能够通过浏览器连接接收服务端 agent 的流式响应，并支持一定的断线重连或恢复。现在需要改进长时间 agent 对话中的取消控制：浏览器刷新、组件卸载、页面切换、reader cancel 或短暂网络断开时，不应轻易中断已经在服务端持续运行且可恢复的 agent turn；但当用户明确点击“停止”或应用主动取消时，系统又应能把取消意图传达到服务端。

不同应用对“客户端断开是否代表取消服务端任务”可能有不同偏好，因此该能力还需要保留可配置空间，并兼容流式响应、恢复、工具调用继续执行和多标签页观察。

请探索给定项目快照，生成一个可用于专利交底书的技术方案草稿。方案应围绕客户端本地清理与服务端 agent turn 取消之间的解耦控制提出合理、深入且可实施的解决方法。
