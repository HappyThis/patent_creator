# 技术方案需求

给定项目快照中的并发限制组件已经能够根据请求时延、当前并发量和丢弃信号动态调整并发上限，并通过采样窗口降低单次请求抖动的影响。实际运行中仍会出现以下问题：极快的探活或轻量请求可能把基准时延拉得过低；用窗口内单个极值代表整段负载容易造成误判；基准时延重新探测的频率会随当前并发上限变化；同一种平滑方式同时作用于上调和下调时，会造成恢复过慢或降载不稳。

现在需要改进该自适应限流机制，使它在负载上升、依赖变慢、请求被丢弃、业务流量未打满以及系统性能基线长期变化等情况下，都能稳定而及时地调整并发上限。方案还应考虑异常时延样本过滤、采样窗口聚合、重新探测、上下界保护、可配置性和运行指标观测，避免因少量异常样本持续漂移或振荡。

请探索给定项目快照，生成一个可用于专利交底书的技术方案草稿。方案应围绕自适应并发限制中的时延测量、负载判定和非对称调节提出合理、深入且可实施的解决方法，不要只给出调参建议或固定并发阈值。
