# 技术方案需求

给定项目快照中的 agent workspace 已经支持模型通过文件工具读取、写入、编辑、列举、搜索和删除持久化工作区文件。现有读取能力主要面向文本文件。现在需要提升 agent 对图片、PDF 或其他非纯文本文件的理解能力：当工作区包含可被多模态模型消费的文件时，系统应尽量将合适的内容传递给模型；对于不适合直接传递的文件，也应返回结构化文件信息和限制原因。

该能力需要保持现有文本读取体验，包括行号、分页、截断和长内容控制；同时需要考虑文件类型识别、大文件限制、普通二进制降级、错误说明，以及真实 workspace、共享 workspace 或自定义文件后端的兼容。

请探索给定项目快照，生成一个可用于专利交底书的技术方案草稿。方案应围绕 workspace 多模态文件读取、模型输出转换、限制控制和多后端兼容提出合理、深入且可实施的解决方法。
