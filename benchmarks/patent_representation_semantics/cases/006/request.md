# 技术方案需求

给定项目快照中的知识管理系统使用 Markdown 文件承载项目知识，并希望这些知识文件适合共享、审阅和版本控制。实际运行中，系统又会不断产生访问次数、检索命中、排序权重、成熟度、近期使用情况等动态信号，这些信号对检索、排序、清理和自动整理有价值。

现在需要避免这些高频变化的运行时信号反复改写共享 Markdown 文件，导致版本控制状态变脏、团队合并冲突增多或真正的知识内容变化被噪声淹没；同时也不能简单丢弃动态信号。

请探索给定项目快照，生成一个可用于专利交底书的技术方案草稿。方案应围绕共享知识文件与本机运行时动态信号的分层存储、读取融合和清理一致性提出合理、深入且可实施的解决方法。
