# Case 012 表达专项标尺

## 配图（optional）

不画图不扣分。本题可完全依靠正文和公式说明机制。若使用配图，可表达稀疏—稠密转换、寄存器逐坐标合并或分布式归并树。只要图中实际画出的对象、方向和状态关系正确，就不因图较简化、偏装饰性或未覆盖全部机制而扣分；把寄存器画成相加/平均、允许不同精度直接错位合并、把顺序无关归因于全局排序，或画出与正文相反的转换方向，应按错误程度扣分。

## 公式（recommended）

高质量公式应共同说明“有限规范状态为何与操作历史无关”“合法合并为何与顺序无关”以及“如何在有界状态上得到经校准的估计”。不限定采用普通 HLL 绝对寄存器或 LogLog-Beta；满足下列核心语义的等价草图结构和估计器均可：

1. 定义精度或容量参数、有限状态空间、确定性哈希映射和幂等插入算子。绝对寄存器逐坐标取最大值是一种实例：

   \[
   M_j\leftarrow\max(M_j,\rho(x))
   \]

2. 定义同精度草图的合并算子，并说明或推导其交换、结合和幂等性质。逐坐标最大值是一种实例：

   \[
   M_j^{A\sqcup B}=\max(M_j^A,M_j^B)
   \]

   \[
   A\sqcup B=B\sqcup A,\qquad
   (A\sqcup B)\sqcup C=A\sqcup(B\sqcup C),\qquad
   A\sqcup A=A
   \]

3. 在规范状态上定义原始估计量以及随精度、占用状态或零寄存器比例变化的校准关系，并给出零值和数值边界。调和和加精度化偏差函数是一种实例：

   \[
   S=\sum_j2^{-M_j},\qquad
   z=\sum_j\mathbf 1[M_j=0]
   \]

   \[
   \widehat N=\operatorname{round}\!\left(
   \frac{\alpha_m m(m-z)}{S+\beta_p(z)}
   \right)
   \]

4. 若方案包含稀疏估计或状态转换，应以公式或明确条件给出其适用边界，并保证转换后的规范状态与遍历顺序无关。例如线性计数可写为：

   \[
   \widehat N_s=m_s\ln\!\left(\frac{m_s}{v}\right),\qquad v>0
   \]

上述方程只是一个可接受实例，不构成唯一答案。方案可以采用其他规范压缩编码、可证明的半格/合并结构，以及经实验或理论标定的等价估计器；不要求逐项列出标定系数，也不要求使用同一种校正函数。必须定义变量、精度或容量条件、必要的表示转换边界和异常值边界，并与正文数据结构及合并流程一致。只有技术关系正确的 \(m=2^p\)、孤立理论误差率或单一估计式，因没有覆盖顺序无关合并等推荐核心关系而应判为 `partially_correct`；把本应幂等的合并写成无界求和或平均、指数方向错误、估计式缺少成立所必需的关键校准输入，或写出不成立的代数性质时，再按实际技术错误扣分。
