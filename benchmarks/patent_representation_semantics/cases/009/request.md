# 技术方案需求

给定项目快照中的 codemode 能力允许模型生成一段代码，由系统在隔离环境中执行这段代码并调用应用提供的工具。现在需要支持浏览器侧场景：有些工具只存在于页面中，例如读取当前页面状态、访问前端组件能力或组合动态客户端工具；开发者希望模型生成代码来编排这些工具，但不希望把浏览器私有能力全部搬到服务端，也不希望生成代码直接污染主页面环境。

该能力需要在浏览器侧隔离执行生成代码，并通过受控协议让主页面真实执行已注册工具。系统还应处理动态工具描述、工具名规范化、非法工具调用、异常传播、日志收集、超时和资源释放。

请探索给定项目快照，生成一个可用于专利交底书的技术方案草稿。方案应围绕浏览器侧隔离执行生成代码并调度动态客户端工具提出合理、深入且可实施的解决方法。
