# Case 014 表达专项标尺

## 配图（recommended）

高质量配图应同时表达断路器状态机和滚动时间桶，而不是只画其中一层。核心语义包括：

1. Closed 经跳闸条件进入 Open，Open 经超时进入 HalfOpen，HalfOpen 失败回到 Open，达到允许探测请求的连续成功条件后回到 Closed。
2. 总窗口由固定宽度的循环桶组成，随逻辑年龄逐桶覆盖最老桶并从聚合中减去其计数；跨越至少一整个窗口时清空全部旧桶，而不是在固定边界整体清空。
3. 请求开始时记录状态代际和桶年龄，请求完成时先校验代际，再按明确规则写入仍有效的桶；旧代际结果不得污染新状态。
4. 分布式共享状态整体保存和恢复状态/代际、当前年龄、聚合计数与桶数组。

可以用一张综合图，也可以组合状态图、桶时间轴和请求时序图。只画三状态而没有滚动桶，或只画桶而没有状态重置关系，属于部分正确；状态转换方向、最老桶过期方向或跨代际记账关系错误，应按技术错误扣分。

## 公式（recommended）

高质量公式应把窗口对齐、桶定位、聚合过期和跳闸输入写成可判定关系。至少应覆盖以下核心语义：

1. 总时长 \(I\) 按桶宽 \(B\) 向上对齐，并定义非零桶数：

   \[
   I'=\left\lceil\frac{I}{B}\right\rceil B,\qquad N=\frac{I'}{B},\qquad B>0,\ N\ge1
   \]

2. 由代际开始时刻 \(t_0\) 计算逻辑年龄和循环槽位：

   \[
   a(t)=\max\!\left(0,\left\lfloor\frac{t-t_0}{B}\right\rfloor\right),
   \qquad j(a)=a\bmod N
   \]

3. 当前聚合等于有效桶之和，轮转时从聚合中减去被覆盖最老桶；若年龄跨度 \(\Delta a\ge N\)，则全部旧桶过期。

4. 若采用失败率跳闸，应定义零请求和最小样本边界，例如：

   \[
   \rho(t)=\frac{F(t)}{R(t)},\qquad
   \operatorname{trip}(t)=(R(t)\ge R_{\min})\land(\rho(t)\ge\theta)
   \]

公式不要求采用失败率作为唯一跳闸条件；连续失败等项目允许的策略也可接受，但窗口、年龄、索引与增量过期关系仍须完整。只有失败率公式而没有滚动窗口数学关系，属于部分正确；未处理不能整除、\(B\le0\)、循环索引方向、过期减法或整窗跳跃条件，或让公式与图中的逐桶过期相矛盾，应按技术错误扣分。
