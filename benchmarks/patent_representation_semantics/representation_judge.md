# 图与公式表达专项评价规则

本子轨在通用技术方案质量之外，独立评价配图和公式是否在适合的场景中被正确使用。图与公式彼此独立；一项的策略和得分不得代替另一项。

本文件是表达专项规则；当通用 `judge.md` 中“图和公式均为可选、不得自动扣分”或“不评价图片视觉质量”的表述与本文件冲突时，以本文件的逐 Case 隐藏策略和 recommended 配图质量规则为准。通用文件的技术方案质量标准仍然有效。

## 两类策略

- `recommended`：该 Case 存在仅靠长段文字不易清楚表达的结构、流程、状态或数学关系。未使用该表达手段时，本通道固定为 40 分，必须产生扣分。
- `optional`：使用或不使用均可。未使用时本通道固定为 100 分，不奖不罚；若决定使用，则必须按实际技术正确性评价。

“optional”不是“不适合”或“禁止”。不得因为正确使用了可选图或公式而扣分，也不得因为可选项未使用而扣分。可选表达只有在其实际写出或画出的技术内容错误、矛盾或误导时才扣分；“没有必要”“帮助有限”或“偏装饰性”本身不是扣分理由。

## 单通道评分

- 未使用：`verdict=not_used`。`optional` 固定 100 分，`recommended` 固定 40 分。
- 使用且技术语义正确、与正文一致：`verdict=correct`。`optional` 通道固定 100 分；即使较简单、装饰性较强或视觉质量一般，只要没有技术错误或误导就不得扣分。`recommended` 公式固定 100 分。`recommended` 配图还必须覆盖逐 Case rubric 指定的核心关系，并按下述配图质量维度在 80 至 100 分内评分。
- 使用但未达到完全正确：`verdict=partially_correct`，40 至 79 分。对 `recommended` 通道，实际表达出的内容虽然正确、但没有覆盖逐 Case rubric 指定的核心关系，可以判为“部分正确”；存在局部歧义或非致命错误时也可以按程度判为“部分正确”。对 `optional` 通道，只有实际写出或画出的内容存在具体错误、歧义或误导风险时才可判为“部分正确”；未覆盖完整机制、表达较简单、帮助有限或偏装饰性本身不得扣分。
- 使用且存在错误关系、错误方向、错误状态、错误数学关系、未定义关键变量，或编造冻结材料不支持的固定权重/阈值：`verdict=incorrect`，0 至 39 分。

只统计最终 disclosure 中实际存在的公式和配图。公式既可以是 formula block，也可以是 paragraph、list、table 等文本 block 中具有明确数学关系的内联或展示 LaTeX；只写变量名或普通符号不算。配图必须被正文或附录实际引用，且能在 figures 资产中定位。聊天里提到、会话轨迹中生成但未进入最终 disclosure 的图或公式不算使用。

## 配图正确性

先检查图中对象、边界、方向、状态、时序、数据流或控制流是否与正文和冻结事实一致，是否覆盖本 Case rubric 指定的关键关系。装饰性通用框图若没有表达指定关系，不能视为正确完成 recommended 配图；若还表达了错误关系，应按错误扣分。

仅对 `recommended` 且实际使用的配图，按以下维度形成图通道分数：

- 技术要素和关键关系完整性：40 分。
- 对技术方案的辅助说明能力：30 分。
- 连线、布局和文字可读性：20 分。
- 黑白技术图风格与整体严肃性：10 分。

清晰可辨但存在轻微对齐、留白或审美问题，不应被过度扣分。渲染失败、文字裁切、悬空或含义不清的连线、过度弯折、严重拥挤、风格混乱等确实妨碍理解或明显偏离严肃工程图气质时，才在对应维度扣分。技术语义完整且无错误的 recommended 配图判为 `correct`，分数限制在 80 至 100；未完整覆盖指定关系或视觉问题已经实质影响理解时判为 `partially_correct`，分数限制在 40 至 79。

## 公式正确性

检查数学关系本身、适用条件、分段边界、变量定义、量纲或取值范围，以及公式与正文机制是否一致。等价变形和等价符号均可接受。对 `recommended` 公式，单纯把普通文字改写成符号而没有表达指定数学关系，不能视为完成推荐表达；对 `optional` 公式，不因关系简单或帮助有限扣分。编造材料不支持的评分权重、概率、阈值，或写出不成立的关系，均应按错误扣分。

## 分数计算

1. `solution_score`：完全按通用规则和基础 Case rubric 评价，范围 0 至 100。
2. `representation_score = (figure.score + formula.score) / 2`。
3. `total_score = 0.7 × solution_score + 0.3 × representation_score`。

派生分可保留不超过两位小数。图或公式的错误首先只在对应表达通道扣分；只有同一个错误主张也写入正文，或该错误确实使正文技术方案不成立、矛盾或不可实施时，才可同时影响 `solution_score`。仅因 recommended 表达缺失而产生的专项扣分，不应再次机械重复扣减 `solution_score`，除非缺失同时使技术方案本身无法理解或不完整。
