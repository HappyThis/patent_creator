# Patent Creator v0.4.1

## 主要更新

- 优化运行中状态展示：过程记录标题会根据当前阶段显示“工具调用中”“上下文压缩中”“增强中”或“文本输出中”。
- 工具调用阶段显示本轮已调用工具总数，便于判断当前处理进度。
- 上下文压缩和增强模式状态统一进入过程记录，不再漂浮在正文外。
- 处理过程默认收起工具调用明细，避免一次展开大量工具记录。
- 美化“正在思考”和过程记录运行态样式，使长任务过程更易读。
- 修复项目侧边栏“运行中”状态不同步的问题。
- 改进后端配置读取、Responses API 重试、流式输出中断恢复、项目恢复、上下文历史和工作区工具稳定性。
- 整理技术方案增强相关后端结构，并补充配置、项目恢复、上下文、OpenAI Responses、增强模式流程等测试覆盖。
