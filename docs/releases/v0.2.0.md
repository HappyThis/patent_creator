# Patent Creator v0.2.0

## 主要更新

- 新增专利交底书 DOCX 导出下载能力。
- 改进公式、行内公式和流程图在预览与导出流程中的渲染效果。
- 围绕项目与会话侧边栏重构工作台 UI，替换旧首页流程。
- 新增会话删除能力和模型异步生成会话标题能力。
- 扩展事件流、恢复、DOCX 导出、上下文、工作区和 benchmark 相关覆盖。
